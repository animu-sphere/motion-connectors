# v0.1.0 — the first release

**Tagged:** 2026-10-04 ·
[Release page](https://github.com/animu-sphere/motion-connectors/releases/tag/v0.1.0)

The first release of `motion-connectors`. It carries the connectors
`usd-vrm-plugins` built and shipped through its v0.8.0, moved here with their
history, converged onto one connector contract, and published as libraries a
consumer pins by digest.

## Objective

Make external motion enter the ecosystem through one boundary. A VMC sender,
the mocopi app and a VRChat OSC tracker sender each speak their own protocol;
after this release, each is decoded by its own connector and handed on as the
same `MotionFrame` through `IMotionConnector`. The motion values inside it
are `usd-motion-plugins`' and are not redefined here. The release also has
to be consumable from outside the repository: every library installs, is
found from a clean prefix, and is published as a digest-pinned artifact.

## What shipped

- **`motionConnectorCore`**: `IMotionConnector`, `MotionFrame`,
  `TrackerObservation`, state, capabilities, timing, actor identity and the
  bounded `Latest` / `Ordered` / `Lossless` frame buffer
  ([CONNECTOR_CONTRACT.md](../design/CONNECTOR_CONTRACT.md)).
- **Three connectors**, each behind the shared contract with its tested
  source-specific assembly kept:
  - `motionConnectorVmc`, profile `vmc.v1`;
  - `motionConnectorMocopi`, profile `mocopi.body.v1`;
  - `motionConnectorVrchatOsc`, profile `vrchat-osc.trackers.v1`. Its tracker
    frames stay observations and are not assigned to an avatar.
- **Three shared leaves**:
  - `motionConnectorTransport`: UDP receive, the packet-capture format and
    the diagnostic vehicle;
  - `motionConnectorOsc`: the OSC 1.0 wire format;
  - `motionConnectorTracking`: tracker assignment and the direct solve.
- **Source profiles** installed under `share/motion-connectors/profiles/` and
  carried inside each connector's artifact
  ([SOURCE_PROFILES.md](../design/SOURCE_PROFILES.md)).
- **CLIs**, built from the source archive:
  - `motion_connect` with `list`, `dump` and `inspect` over `MotionFrame`;
  - the capture tools `vmc_record`, `mocopi_record` and `vrchat_osc_record`,
    one per connector (WS-O3).
- **Basis**: VMC and VRChat OSC convert through `motionCore`'s shared basis
  operation (CS-O1).
- **Diagnostics**: the `VMC_*`, `MOCOPI_*` and `VRCHAT_OSC_*` families are
  named consistently (DIAG-O1).
- **Release machinery**: [release.yml](../../.github/workflows/release.yml)
  ([README.md](README.md#how-a-release-is-cut)).

The capabilities, feature by feature, are the
[capability matrix](../reference/CAPABILITY_MATRIX.md) at this tag, and the
change by change detail is the [changelog](../../CHANGELOG.md).

## Evidence

- **Corpus replay**: every committed capture replays through the hardware-free
  `PushDatagram` → `Poll` path in CI on all three platforms, with each
  protocol's end-of-capture handling.
- **Installed prefix**: the installed prefix is consumed by a project outside
  the repository, and the installed `motion_connect` runs `list`, `dump` and
  `inspect` from it.
- **Device sessions**: the eleven recorded mocopi and VRChat OSC device
  sessions, whose bytes are not in the repository, were replayed from an
  operator's copy on 2026-10-04 with `scripts/check_recorded_sessions.py`.
  Every manifest reading was reproduced, and `motion_connect` delivered the
  same frames.

## Compatibility

- **OpenUSD:** 26.08, exactly
  ([DEPENDENCIES.md §1](../architecture/DEPENDENCIES.md#1-openusd)).
- **`usd-motion-plugins`:** 0.5.2, pinned by digest in each library's
  manifest ([DEPENDENCIES.md §2](../architecture/DEPENDENCIES.md#2-usd-motion-plugins)).
- **Platforms:** Windows x86_64, macOS arm64, Linux x86_64, each as the
  OpenStrata `cy2026` / `usd` target with Python 3.13.
- **Packages:** every library is version 0.1.0, and a consumer requires
  `>=0.1,<0.2`.

## Artifacts

Per target: `<library>-0.1.0-<target>.tar.zst` and its `.manifest.json` for
each of the seven libraries, each also pushed to
`ghcr.io/animu-sphere/motion-connectors` as `<library>-0.1.0-<target>`. Once:
`motion-connectors-0.1.0-src.tar.gz`, `SHA256SUMS`, and the pin table
`external-library-pins.md` / `.json`
([WORKSPACE.md §4.1](../architecture/WORKSPACE.md#41-distribution)).

## Known limitations at this release

- **The CLIs are not published as artifacts.** `ost` packages a workspace
  tool only alongside a plugin bundle, and this repository has none, so they
  are built from the source archive.
- **One actor per source.** `ActorId`'s type waits for the first multi-actor
  source (CC-O5).
- **No VMC sender has been recorded**, so VMC's two translation channels are
  unsettled (CS-O2) and VMC rests on generated captures alone.
- **The VRChat OSC tracker Euler order** is measured to three compositions of
  six, because no recorded take rolls.
- **`MOCOPI_TRACKING_LOST` is reserved and never raised.** No recorded stream
  carries a lost sensor.
- **No mocopi capture is redistributable**, so the device sessions are
  manifest rows only.
- **Only the three UDP sources exist.** WebSocket, bindings, browser, XR and
  `motion_connect record` / `bridge` are later releases
  ([roadmap](../roadmap/README.md#status-at-a-glance)).
